# Changelog

All notable changes to the FlipToFocus project will be documented in this file.

## [1.0.0] - 2026-06-14
### Added
- Complete End-to-End flow: Flutter frontend connected to FastAPI backend.
- Accelerometer integration for physical focus triggers.
- JWT-based authentication system.
- Offline storage fallback for focus sessions.
- Fully automated CI/CD pipelines for testing and APK builds.
